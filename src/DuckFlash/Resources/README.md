# Resources

Folder ini menyimpan data non-kode yang dibaca aplikasi saat runtime:

- `error-mappings.json` — daftar pemetaan error mentah dari adb/fastboot ke penjelasan
  bahasa Indonesia beserta solusinya. Dipakai oleh `Services/ErrorTranslator`.
  (Diisi pada task 1.11.)
- Ikon, gambar, dan string UI statis.

Semua teks yang tampil ke pengguna harus berbahasa Indonesia.
